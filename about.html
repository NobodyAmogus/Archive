About

Why this exists

What it is

A personal archive of things I've built, broken, half-finished, or just found interesting enough to keep. Not a résumé — I never cleaned it up to look impressive, and I'm not planning to.

Why it exists

I kept losing track of my own work — old projects buried in random folders, screenshots I couldn't find again, notes I'd written once and then forgotten I'd written. This is where all of that lives now, in one place I actually check.

What's stored here

Software projects, small experiments, game mods, electronics tinkering, school notes, tutorials I wrote for myself, and a gallery of screenshots and images that didn't fit anywhere else. Unfinished and abandoned things are kept on purpose — they're as much a record as the finished ones.

How it's built

Static HTML, CSS and JavaScript, hosted on GitHub Pages. Every entry is a JSON file in /content — adding something new means editing a data file, not rebuilding the site.

The Archive — updated whenever something's worth keeping. Built with plain HTML, CSS & JS.
